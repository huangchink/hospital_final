------------------------------------------------------------------------------
 SOL GAZE ACCURACY TEST  (VA_center_opt - "Sol Calib" tab)  -- fix, v1.0.1
------------------------------------------------------------------------------
Previously the accuracy test showed the targets only on the subject's screen,
so the operator had no way to tell whether the subject was actually fixating
the target before recording a point - off-target samples could be recorded
without anyone noticing.

  - Tester monitoring window (new): when a separate Tester Screen is configured,
    an operator-only window opens on that screen. It shows a small picture of
    the subject's screen with:
          * the target                 (red cross)
          * the subject's live gaze     (green dot; faint gray = raw, before offset)
          * the live target->gaze offset in pixels and degrees
    Watch the green dot settle on the red target, then press SPACE to record.
    While recording it shows "COLLECTING x/30 - subject must hold fixation".

  - The monitoring view is shown ONLY on the tester screen - nothing is drawn on
    the subject's screen. This is deliberate: if the subject could see their own
    gaze dot they would move their eyes to chase it onto the target, which would
    corrupt the accuracy measurement.

  - SPACE (record) and Q (abort) now work even if you have clicked the tester
    window (it no longer matters which window has the keyboard focus).

  How to turn it on:
      * "Sol Calib" tab -> Display -> set "Tester Screen" to a DIFFERENT monitor
        than the accuracy test's screen ("Preview Gaze Mapping" -> "Screen").
      * With a single monitor (or both set to the same screen) the accuracy test
        behaves exactly as before - no tester window.
